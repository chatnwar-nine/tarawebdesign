# Vael — AI agent site concept

Design concept for a fictional AI finance agent. Open `index.html` in a browser. No build step.

## Brand
- **Name:** Vael — short, soft, ownable.
- **Mark:** one stroke + one point. The stroke is the work the agent does. The point is the decision the human approves. It reads as a "V".
- **Type:** Funnel Display (headlines, tracking −0.045 to −0.06em), Geist (body), Geist Mono (system details).
- **Color:** ink `#0A0A0A`, paper `#F3F3EE`, neon `#E6FF2B`. Neon marks action and proof only.

## Page flow
Hero (live agent console) → logos → 01 How it works → 02 What it does → 03 Results → 04 Customers → 05 Trust → integrations + pricing → 06 CTA.

## Interactions
- Hero dot field bends and lights up under the cursor. It ripples when the agent runs or you approve.
- Agent console: pick a task or type your own (⌘K). Vael streams each step, then asks for approval.
- Sticky scroll story in section 01.
- Dithered orb in section 03: the light follows the cursor.
- Side progress rail, count-up stats, scroll reveals. Respects `prefers-reduced-motion`.

All companies, people and figures are fictional.
